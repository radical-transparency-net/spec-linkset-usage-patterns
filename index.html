This specification defines ten interlocking Web-Linking and RFC 9264 Linkset usage patterns (RT-P01 through RT-P10) that formalize the foundational Declare layer of the Radical Transparency interoperability architecture. Building strictly on mature IETF, W3C, IANA, and OAI standards, these patterns enable digital resources, APIs, catalogs, and local files to declare profile conformity, available representations, persistent identity, and structural relationships in a machine-actionable way.

This is an unofficial community working draft maintained by the Radical Transparency Network at the Flanders Marine Institute (VLIZ). Feedback, cross-standard alignment notes (OGC, CODATA/CDIF, EOSC, FAIR Signposting), and pull requests are welcomed via the GitHub repository.

The companion RDF reification vocabulary referenced in The Semantic Bridge (rtwl:) is maintained in radical-transparency-net/semantic-assets.
